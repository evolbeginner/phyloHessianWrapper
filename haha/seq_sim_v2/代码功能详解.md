
# seq_sim v1.0.0 — 分子序列演化模拟器 代码详解

## 一、项目概述

`seq_sim_v2` 是一个用 Python 编写的**蒙特卡洛分子序列演化模拟器**，灵感来源于经典的 Seq-Gen（Rambaut & Grassly, 1997）。该程序根据用户指定的系统发育树和替换模型，模拟 DNA 或蛋白质序列的演化过程。

**技术栈**：Python >= 3.9、NumPy、SciPy  
**许可证**：MIT  
**项目根目录**：`C:\Users\intot\Desktop\molecular_clock\practice\seq_stimulation\seq_sim_v2`

## 三、逐文件详解

### 3.1 根目录

#### `__init__.py`
- 包初始化文件。
- 从 `seq_sim.py` 导出 `main` 函数和 `VERSION` 常量。
- 设置 `__version__` 属性。

#### `__main__.py`
- 支持 `python -m seq_sim_v2` 方式启动。
- 仅一行核心代码：`from .seq_sim import main; main()`。

#### `README.md`
- 项目文档：版本号（1.0.0）、安装方法、快速入门示例。
- 归因说明：算法参考 Seq-Gen，纯 Python 重写。
- 学术引用：Yang(1994)的离散Gamma方法、Foster(2004)的时间可逆模型矩阵方法、各经验氨基酸模型(JTT/WAG/PAM/BLOSUM/LG)的原始论文。

#### `seq_sim.py`（主程序，~971行）

这是整个程序的入口文件和核心调度中心。主要包含：

**`main()` 函数**（第21-201行）：
1. 解析命令行参数（调用 `_parse_args()`）。
2. 设置随机种子（`utils.set_seed`），确保结果可重现。
3. 读取输入树文件或标准输入，检测是否为 NEXUS 格式。
4. 若是 NEXUS，调用 `parse_nexus_trees()` 解析。
5. 构建替换模型：`setup_model()` 创建主模型，`build_model_registry()` 构建节点异质性模型注册表。
6. 处理速率异质性：Gamma（连续/离散）、密码子位置速率、不变位点。
7. 解析 Newick 树（`parse_trees`），处理生根标志。
8. 分组分区（`_group_partitions`）。
9. 循环模拟：对每个复制和每个分区进行序列演化（`evolve_sequences`）。
10. 输出结果：PHYLIP / Relaxed PHYLIP / NEXUS / FASTA。

**`_parse_args()` 函数**（第675-814行）：
- 基于 `argparse` 的命令行参数解析器。
- 支持的参数（~30个）与 Seq-Gen 兼容：

| 参数 | 含义 |
|------|------|
| `-m` / `--model` | 替换模型名称（JC69, HKY, F84, GTR/REV, JTT, WAG, PAM, BLOSUM, LG, GENERAL） |
| `-l` / `--length` | 序列长度（模拟的位点数） |
| `-t` / `--kappa` | 转换/颠换比（transition/transversion ratio） |
| `-f` / `--freqs` | 碱基/氨基酸频率 |
| `-r` / `--rates` | 相对替换速率（GTR/AA模型） |
| `-a` / `--alpha` | Gamma分布形状参数 |
| `-g` / `--gamma-cats` | 离散Gamma类别数 |
| `-c` / `--codon-pos-rates` | 密码子位置速率 |
| `-i` / `--invar` | 不变位点比例 |
| `-s` / `--scale` | 分支长度缩放因子 |
| `-n` / `--reps` | 复制次数 |
| `-br` / `--branch-rates` | 每分支速率乘数 |
| `-o` / `--output` | 输出路径（默认标准输出） |
| `-or` / `--output-format` | 输出格式 |
| `-z` / `--seed` | 随机种子 |
| `-k` / `--ancestral` | 祖先序列输出 |
| `-wr` / `--write-rates` | 写出位点速率 |
| `--alt-freqs` | 替代频率向量（节点异质性） |
| `--alt-rates` | 替代速率矩阵（节点异质性） |
| `--alt-tstv` | 替代ts/tv比（节点异质性） |

**`_print_manual()` 函数**（第232-672行）：
- 打印10个章节的完整用户手册，涵盖所有模型、速率异质性、分支缩放、输出格式、节点异质性模型、NEXUS输入、常用工作流、故障排除等。

辅助函数：
- `_setup_rates()`：构建速率信息字典。
- `_assign_categories()`：为每个复制分配随机速率类别/Gamma值。
- `_group_partitions()`：按序列长度分组。
- `_parse_alt_vectors()`：从CLI或文件解析替代频率/速率向量。
- `_normalize_branch_rates()`：归一化分支速率，使加权均值为1.0。

### 3.2 `core/` — 核心演化引擎

#### `core/__init__.py`
- 重新导出所有核心类：`setup_model`, `build_model_registry`, `NUC_MODELS`, `AA_MODELS`, `JC69Model`, `HKYModel`, `F84Model`, `GTRModel`, `AAModel`, `create_aa_model`, `rndgamma`, `discrete_gamma`, `evolve_sequences`, `_raise_recursion_limit`。

#### `core/_validators.py`（~85行）
- 所有替换模型共用的参数校验函数：
  - `validate_nuc_freqs()` — 验证4个核苷酸频率为正数且和为1.0。
  - `validate_aa_freqs()` — 验证20个氨基酸频率为正数且和为1.0。
  - `validate_state()` — 验证状态索引在有效范围内。
  - `validate_length()` — 验证分支长度为非负浮点数。
  - `validate_output_array()` — 验证输出数组大小正确、浮点类型、可写。
  - `normalize_freqs()` — 原地归一化频率列表。

#### `core/nuc_models.py`（~414行）
实现4种核苷酸替换模型，每种模型的核心任务是计算转移概率矩阵 `P(t)`——给定分支长度 `t`，矩阵元素 `P_ij(t)` 表示从状态 `i` 突变到状态 `j` 的概率。

| 模型 | 行号 | 方法 | 说明 |
|------|------|------|------|
| **JC69Model** | 14-58 | 闭合形式 | Jukes-Cantor 1969。等频率(0.25)，等速率。公式：P_ii = 1/4 + 3/4*exp(-4t/3) |
| **HKYModel** | 61-134 | 闭合形式 | Hasegawa-Kishino-Yano 1985。区分转换/颠换(kappa)，允许不等频率。预计算每状态的表格化常量。 |
| **F84Model** | 137-222 | 闭合形式 | Felsenstein 1984。与HKY类似的闭合形式结构，但使用xi/xv参数化。 |
| **GTRModel** | 225-343 | 特征值分解 | 广义时间可逆模型。通过对称化 Q = R*diag(pi) 后做 `eigh()` 特征分解来求解 P(t)。 |

速度优化：GTR的 `set_matrix()` 会预分解并缓存特征向量和特征值；`set_vector()` 调用时可复用缓存结果。

辅助函数：
- `_fill_matrix()` — 从HKY/F84闭合形式表达式构建4×4原始概率矩阵，然后按行做 `cumsum`。
- `_fill_vector()` — 为HKY/F84矩阵构建单行。

#### `core/aa_models.py`（~317行）
实现氨基酸替换模型（20种状态：ARNDCQEGHILKMFPSTWYV，即 Ala, Arg, Asn, Asp, Cys, Gln, Glu, Gly, His, Ile, Leu, Lys, Met, Phe, Pro, Ser, Thr, Trp, Tyr, Val）：

- **`AAModel`**（第14-127行）：通用的20态特征分解模型。构建20×20速率矩阵（从190个相对速率和20个平衡频率），对称化后分解，与GTR方法相同。提供 `set_matrix()` 和 `set_vector()`。也支持特征分解缓存。
- **`create_aa_model()`**（第130-154行）：工厂函数。对于命名经验模型（JTT, WAG, PAM, BLOSUM, LG），加载内置速率/频率并允许用户覆盖。对于 GENERAL，要求用户提供速率和频率。
- **`_EMPIRICAL_MODELS`**（第159-317行）：内置5种经验模型的字典：
  - **JTT** — Jones-Taylor-Thornton 1992
  - **WAG** — Whelan & Goldman 2001
  - **PAM** — Dayhoff 1978（包含一些零交换率）
  - **BLOSUM** — 基于BLOSUM62
  - **LG** — Le & Gascuel 2008
  - 每种包含 `rates`（190个浮点数）和 `freqs`（20个浮点数）。

#### `core/models.py`（~100行）
- **`setup_model()`**（第12-42行）：创建单个替换模型实例。支持所有核甘酸模型（JC69, HKY, F84, GTR/REV）和所有氨基酸模型，带可选频率/速率覆盖。
- **`build_model_registry()`**（第45-100行）：构建一个以 `(comp_idx, rmat_idx)` 元组为键的字典。支持替代频率向量（`--alt-freqs`）、替代速率矩阵（`--alt-rates`）和替代ts/tv比（`--alt-tstv`）。创建成分索引和速率矩阵索引的完整笛卡尔积。用于**节点异质性模拟**——树中不同节点可以使用不同的替换模型。

#### `core/evolve.py`（~180行）
这是最核心的蒙特卡洛演化引擎：

- **`evolve_sequences()`**（第8-33行）：顶层函数。
  1. 从平衡频率生成随机根序列（或使用用户提供的祖先序列）
  2. 预计算位点速率（`_set_site_rates`）
  3. 从根节点递归演化到所有叶节点（`_evolve_node`）
- **`_raise_recursion_limit()`**（第36-40行）：确保Python递归限制超过树深度+100，防止深层树导致递归溢出。
- **`_random_sequence()`**（第43-50行）：使用累积频率分布和种子RNG生成随机根序列。
- **`_set_sequence()`**（第53-62行）：将编码的祖先序列字符串复制到节点缓冲区，验证字符与模型状态字母表匹配。
- **`_evolve_node()`**（第65-76行）：递归前序遍历。将父序列复制到子节点，应用突变（`_mutate_sequence`），然后递归到子的后代。
- **`_mutate_sequence()`**（第79-123行）：**核心突变循环**，处理三种速率异质性模式：
  - **离散Gamma**（第91-107行）：预计算每类别的完整转移矩阵（速度优化），然后对每个位点应用适当的矩阵行，通过 `_pick_state_from_matrix()` 抽取新状态。
  - **均匀/密码子/连续Gamma**（第108-120行）：计算每位点的有效分支长度（= branch_length * site_rate * branch_param），调用 `set_vector()` 获取单个转移概率行，通过 `_pick_state()` 抽取新状态。
  - **不变位点**：速率=0的位点在上述逻辑中被跳过（直接检测 site_rate == 0），不发生突变。
- **`_pick_state()`**（第126-132行）：从累积概率向量中随机抽取状态（使用 `utils.random()` + 二分查找/线性扫描）。
- **`_pick_state_from_matrix()`**（第135-141行）：从扁平概率矩阵的给定行中随机抽取状态（预计算矩阵的位移索引）。
- **`_set_site_rates()`**（第144-180行）：为 `-wr` 输出选项预计算每位点的相对速率。支持：
  - 均匀速率（全部1.0）
  - 连续Gamma（每复制重新生成）
  - 离散Gamma类别
  - 密码子位置模式
  - 不变位点（0.0）

#### `core/gamma.py`（~115行）
Gamma分布工具，实现 Yang(1994) 的速率异质性方法：

- **`rndgamma()`**：生成单个 Gamma(shape, 1) 随机变量。
- **`_gamma_ppf()`**：Gamma分位数函数（基于 `scipy.stats.gamma.ppf`）。
- **`discrete_gamma()`**：实现 Yang(1994) 离散Gamma方法。将 Gamma(alpha, alpha) 分布分为 k 个等概率速率类别，均值为1.0。使用三级回退级联方法：
  1. **均值法**：通过 `scipy.special.gammainc` 积分每区间的条件均值。
  2. **中位数法**：使用等概率区间的条件中位数（`scipy.stats.gamma.ppf`）。
  3. **等间距回退**：处理极端参数（如 alpha 趋近于 0 或极大）时使用粗略的网格采样，并替换零值为极小正数。

### 3.3 `output/` — 输出格式化

#### `output/__init__.py`
- 导出：`write_sequences`, `write_ancestral`, `write_rates`, `is_nexus`, `parse_nexus_trees`。

#### `output/writers.py`（~177行）
所有输出格式的写入器：

- **`write_sequences()`**（第4-18行）：调度器，根据 `--output-format` 参数路由到具体格式。
  - **`_write_phylip()`**（第21-32行） — 严格PHYLIP格式：10字符补齐名称、无前导空格、分区交叉排列（所有分区的第一个块、第二个块交替）。
  - **`_write_relaxed_phylip()`**（第35-46行） — 宽松PHYLIP：完整分类名、空格分隔。
  - **`_write_nexus()`**（第49-76行） — NEXUS DATA块：含 `Dimensions`、`Format`（DNA/PROTEIN）、`Matrix` 段（60字符折行），支持多树/多数据集注释。
  - **`_write_fasta()`**（第79-92行） — 标准FASTA：`>` 头 + 72字符折行序列。
- **`write_ancestral()`**（第95-106行）：以FASTA或PHYLIP风格写出内部节点（祖先）序列。内部节点编号从 `num_tips + 1` 开始。递归遍历节点列表，打印非叶节点的序列。
- **`write_rates()`**（第172-177行）：以编号表格写出每位点的相对替代速率（从1到序列长度编号）。

#### `output/nexus_reader.py`（~132行）
轻量级正则表达式NEXUS读取器：

- **`is_nexus()`**：通过检查 `#NEXUS` 或 `BEGIN ... ;` 模式检测NEXUS格式。
- **`_strip_bracket_content()`**：移除所有 `[...]` 内容，处理嵌套括号（用计数器跟踪括号深度）。
- **`_parse_translate()`**：解析 TRANSLATE 命令，返回 `{整型ID: 分类名}` 映射字典。
- **`_extract_tree_newicks()`**：从 TREES 块中提取干净的 Newick 字符串和 rooted 标志（处理 TREE 和 UTREE 命令），移除注释块并规范空白。
- **`_detect_rooted()`**：检测 `[&R]`（有根）或 `[&U]`（无根）标记，返回 rooted 标志列表。
- **`parse_nexus_trees()`**：顶层NEXUS解析器，返回 `(translate_map, [(newick_str, rooted_flag), ...])`。兼容 BEAST、MrBayes、IQ-TREE 的 NEXUS 输出。

### 3.4 `tree/` — 树数据结构与解析

#### `tree/__init__.py`
- 导出：`TNode`, `TTree`, `ParseError`, `parse_trees`, `count_trees`, `allocate_sequences`, `dispose_tree`。

#### `tree/tree_parser.py`（~409行）
完整的树数据结构和Newick解析器：

**`TNode`**（第6-22行，使用 `__slots__` 优化内存）：

| 属性 | 类型 | 含义 |
|------|------|------|
| `branch0` | TNode | 父节点引用 |
| `branch1` | TNode | 第一个子节点 |
| `branch2` | TNode | 第二个子节点（或无根树的第三个子节点） |
| `length0` | float | 到父节点的分支长度 |
| `length1` | float | 到第一个子节点的分支长度 |
| `length2` | float | 到第二个子节点的分支长度 |
| `param` | float | 每分支速率乘数（从 `[value]` 注释解析） |
| `comp_idx` | int | 成分索引（从 `[f=N]` 注释解析，节点异质性模型用） |
| `rmat_idx` | int | 速率矩阵索引（从 `[r=N]` 注释解析，节点异质性模型用） |
| `tip_no` | int | 叶节点编号（0到num_tips-1），内部节点为-1 |
| `sequence` | ndarray | 序列缓冲区（numpy int32数组，长度为位点数） |

**`TTree`**（第25-40行，使用 `__slots__` 优化内存）：

| 属性 | 含义 |
|------|------|
| `root` | 根节点引用 |
| `node_list` | 所有节点的有序列表（拓扑顺序） |
| `num_tips` | 叶节点数量 |
| `num_nodes` | 总节点数量（含内部节点） |
| `total_length` | 总树长（所有分支长度之和） |
| `rooted` | 是否显式声明为有根树 |
| `names` | 字典：{叶节点编号: 分类名} |
| `tips` | 字典：{分类名: TNode}，用于按名称快速查找叶节点 |
| `partition_length` | int，分区序列长度 |
| `partition_rate` | float，分区速率乘数 |

**`_NewickParser`**（第71-365行）：手工实现的递归下降解析器：
- 逐字符级别辅助函数（`_peek`, `_advance`, `_skip_space`, `_require`）。
- 名称解析：无引号名（含数字、下划线）和单引号名（处理 `''` 转义为 `'`）。
- 数值标记读取（支持科学计数法如 `1.5e-3`）。
- 元数据解析：`:branch_length` 和 `[...]` 注释。
  - `[f=N]`：成分索引（frequency composition index）
  - `[r=N]`：速率矩阵索引（rate matrix index）
  - `[value]`：裸数值 → 分支速率乘数（`param`）
- 分区前缀解析：`[length]` 或 `[length, rate]`（用于多分区数据）。
- 完整递归下降解析括号 `()` 分隔的子树。
- Rooted vs unrooted 自动检测（2个子节点=有根，3个子节点=无根）。
- 显式拒绝多分叉树（超过3个子节点抛出 ParseError）。

**`parse_trees()`**（模块级函数）：对输入字符串解析一棵或多棵树，返回 `(tree_list, is_rooted)`。

**`count_trees()`**：快速统计分号分隔的树个数（不完整解析）。

**`_compute_tree_height()`**（第368-387行）：使用迭代栈式DFS计算从根到叶的最大路径长度。仅用于设置递归限制，不用于算法逻辑。

**`allocate_sequences()`**（第390-393行）：为所有节点分配 `np.zeros(num_sites, dtype=np.int32)` 数组。

**`dispose_tree()`**（第396-409行）：清除所有节点的序列缓冲区并重置树到初始状态，以便跨复制复用（避免重复分配内存）。

### 3.5 `utils/` — 随机数生成

#### `utils/__init__.py`（~33行）
种子随机数生成工具（模块级 `numpy.random.Generator` 单例，明确非线程安全）：

- **`set_seed(seed)`**：用给定整数种子初始化全局 `numpy.random.Generator`（使用 `PCG64` 算法）。
- **`create_seed()`**：从系统时间（微秒，掩码到32位）生成种子。当用户未显式指定种子时使用。
- **`random()`**：返回 [0, 1) 范围内的均匀随机浮点数（`generator.random()`）。
- **`gamma(shape)`**：从种子RNG返回 Gamma(shape, 1.0) 随机变量（`generator.gamma(shape, 1.0)`）。

所有需要随机性的模块（`evolve.py`、`gamma.py`）都通过 `from .utils import random, gamma` 使用这些全局RNG函数，从而确保设置了相同种子后结果完全可重现。

## 五、数学背景

### 5.1 转移概率矩阵 P(t)

模拟的核心问题是：给定分支长度 t（期望的每位点替换数量），计算从状态 i 到状态 j 的转移概率 P_ij(t)。

这通过计算矩阵指数求得：`P(t) = exp(Q * t)`

其中 Q 是瞬时速率矩阵（instantaneous rate matrix），其非对角线元素 Q_ij 表示从 i 到 j 的瞬时速率，对角线元素 Q_ii = -sum_{j≠i} Q_ij 保证行和为0。

### 5.2 闭合形式 vs 特征值分解

| 方法 | 适用模型 | 原理 |
|------|---------|------|
| 闭合形式 | JC69, HKY, F84 | 利用对称性得到解析公式，O(1)计算 |
| 特征分解 | GTR, 所有AA模型 | 对称化 Q → 求特征值和特征向量 → P(t) = U * diag(exp(λ*t)) * U^(-1)，O(n³)但可缓存 |

### 5.3 速率异质性（Yang 1994）

Gamma分布允许不同位点以不同速率演化。离散Gamma近似将连续Gamma(α,α)分为k个等概率区间，每个区间取其均值或中位数作为代表速率。这样每个位点随机分配到k个速率类别之一，实现"快位点"和"慢位点"的分化。

### 5.4 不变位点 (+I)

在总位点中取比例 p 为不变位点（速率为0，完全不发生突变），剩余 (1-p) 位点按Gamma或均匀速率演化。

## 六、关键特性总结

| 特性 | 说明 |
|------|------|
| **替换模型** | 核苷酸：JC69, HKY, F84, GTR(REV)；氨基酸：JTT, WAG, PAM, BLOSUM, LG, GENERAL（用户自定义） |
| **矩阵求解** | 闭合形式（JC69/HKY/F84）或特征值分解（GTR/AA） |
| **速率异质性** | 连续Gamma、离散Gamma（Yang 1994）、密码子位置速率、不变位点（+I） |
| **节点异质性** | 不同节点可使用不同的频率向量/速率矩阵/ts:tv比（[f=N] / [r=N] 注释） |
| **分支缩放** | 全局缩放因子（-s）、每分支速率乘数（[value] 注释） |
| **输入格式** | Newick（带/不带注释）+ NEXUS（BEAST/MrBayes/IQ-TREE兼容） |
| **输出格式** | 严格PHYLIP、宽松PHYLIP、NEXUS、FASTA |
| **特殊输出** | 祖先序列（-k）、位点速率（-wr）、分区数据 |
| **可重现性** | 基于种子的固定随机数生成（-z） |
| **性能优化** | `__slots__` 节点/树结构、离散Gamma预计算矩阵、特征分解缓存、迭代树高计算 |
